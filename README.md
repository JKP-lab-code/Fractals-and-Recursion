## Project Description

This project explores mathematical concepts of fractals and recursion through Python programming and visualization. It demonstrates how recursive functions and iterative algorithms can generate complex geometric patterns and explores mathematical properties of fractals through computational analysis.

### 1. Koch Snowflake

The Koch Snowflake is a fractal generated by repeatedly subdividing line segments and constructing triangular protrusions using a 60-degree rotation.

This part of the project includes:
- Recursive construction of the Koch Curve and Koch Snowflake.
- Visualization of the fractal at different recursion depths.
- Calculation of the number of segments and perimeter at different depths.
- Calculation of area using the Shoelace Formula.
- Counting recursive function calls.
- Data collection and export to CSV files.
- Graphical analysis of the relationship between recursion depth, perimeter, and area.

### 2. Sierpiński Triangle

The Sierpiński Triangle is a fractal generated through recursive subdivision of a triangle into three smaller triangles, excluding the central region at each iteration.

This part of the project includes:
- Recursive subdivision of a triangle.
- Generation of the Sierpiński Triangle at different recursion depths.
- Visualization of the resulting fractal pattern.

### 3. Chaos Game

The Chaos Game is an iterative method for generating fractal patterns by repeatedly selecting a vertex of a triangle at random and moving a point halfway toward the selected vertex.

This part of the project includes:
- Implementation of the Chaos Game algorithm.
- Random selection of vertices.
- Visualization of the generated points.
- Comparison of fractal patterns at different numbers of iterations.

### 4. Recursive Function and Call Tree

This part introduces recursive functions and the concept of a call tree to illustrate how a recursive function calls itself and how these calls are structured.

## How to Run the Code

### Requirements
- Python 3
- Jupyter Notebook
- NumPy
- Matplotlib
- Pandas

### Installation

Install the required libraries using the following command:

```bash
pip install numpy matplotlib pandas
```

### Execution

The programs are implemented in Jupyter Notebook. To execute them:

1. Open the corresponding Jupyter Notebook for the fractal you want to explore.
2. Run the notebook cells sequentially.
3. Adjust the recursion depth or number of iterations as specified in each program to explore different fractal patterns and results.

#### Koch Snowflake
- Set the recursion depth to generate and visualize the Koch Snowflake.
- Generate a Koch Curve representing a single side of the snowflake.
- Calculate the number of segments, perimeter, area, and recursive function calls at different depths.
- Export collected data to CSV files.
- Generate graphs to investigate the relationship between recursion depth, perimeter, and area.

#### Sierpiński Triangle
- Set the recursion depth to recursively subdivide the initial triangle.
- Visualize the resulting Sierpiński Triangle using Matplotlib.

#### Chaos Game
- Set the number of iterations to control the number of points generated.
- Randomly select a triangle vertex and move the current point halfway toward the selected vertex at each iteration.
- Plot the generated points to visualize the Sierpiński Triangle pattern.
